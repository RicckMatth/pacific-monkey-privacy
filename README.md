# Política de Privacidade — Pacific Monkey

Esta é a página pública de privacidade da extensão **Pacific Monkey** (Chrome).

## Publicar no GitHub Pages

1. Acesse [Settings → Pages](https://github.com/RicckMatth/pacific-monkey-privacy/settings/pages).
2. Em **Build and deployment**, configure **Source: Deploy from a branch**.
3. Em **Branch**, selecione **main** e **/(root)**.
4. Clique em **Save** e aguarde o GitHub concluir o primeiro deploy.

**Endereço público depois de publicado:** https://ricckmatth.github.io/pacific-monkey-privacy/

O documento exibido no site é o arquivo [index.html](./index.html).

## Uso na Chrome Web Store

Insira o endereço público acima no campo **Privacy policy URL**, na seção **Privacy practices** do painel de desenvolvedor da Chrome Web Store.

> A página declara as práticas da extensão Pacific Monkey 1.7.1. Scripts de terceiros importados e ativados pelos usuários podem acessar ou transmitir dados conforme o próprio código. Revise a política caso as funcionalidades mudem.
