Pacific Monkey · Privacidade e transparência

Política de Privacidade

Como o gerenciador de scripts Pacific Monkey trata permissões, arquivos, códigos personalizados e informações de páginas acessadas.

Última atualização: 31 de outubro de 2026 · Referente à extensão Pacific Monkey 1.7.1

1. Finalidade

O Pacific Monkey é uma extensão para Google Chrome que permite criar, importar, visualizar, editar, ativar e desativar scripts JavaScript em sites escolhidos pelo próprio usuário.

2. Informações utilizadas

  • Scripts e preferências: o código dos scripts, seus nomes, padrões de endereço, estado de ativação e configurações ficam armazenados localmente por meio do chrome.storage.local.
  • Permissões por site: o usuário escolhe o domínio em que pretende executar o script e autoriza o acesso usando o diálogo de permissões do Chrome. A execução utiliza a API chrome.userScripts.
  • Arquivos protegidos por senha: pacotes .pmenc são descriptografados localmente. A senha não é armazenada ou enviada a servidores pelo Pacific Monkey. Após a importação, o script fica disponível em texto legível no armazenamento local, para permitir edição e execução.
  • Conteúdo de páginas: scripts expressamente ativados pelo usuário podem ler ou modificar informações das páginas para as quais receberam autorização, dependendo das instruções contidas em cada script.

3. Uso e transmissão de dados

A versão descrita nesta política não possui sistema próprio de contas, serviço de sincronização remota, telemetria, anúncios ou funcionalidade de envio automático de scripts e conteúdo de páginas ao desenvolvedor.

Atenção aos scripts importados: um script JavaScript criado ou obtido de terceiros pode conter instruções para acessar, processar ou transmitir dados a outros serviços. O Pacific Monkey não garante o comportamento nem a privacidade de scripts de terceiros. Revise o código e use apenas scripts de fontes confiáveis.

4. Armazenamento, retenção e exclusão

As configurações e os scripts permanecem no perfil local do Chrome enquanto o usuário os mantém. É possível excluir scripts diretamente pela biblioteca da extensão. A remoção dos dados da extensão ou sua desinstalação está sujeita ao funcionamento e às políticas do navegador.

5. Permissões do navegador

  • storage: guardar scripts e configurações localmente.
  • userScripts: registrar scripts personalizados autorizados pelo usuário.
  • optional_host_permissions para endereços HTTP e HTTPS: permitir que a extensão solicite acesso aos sites escolhidos pelo usuário. A declaração de permissões opcionais não equivale à autorização automática para todos os sites.

6. Segurança

Recomendamos inspecionar scripts importados antes de ativá-los, evitar códigos de procedência desconhecida e respeitar as normas de segurança dos sites e ambientes de trabalho. A criptografia de um arquivo .pmenc protege o pacote durante seu transporte ou armazenamento externo, mas não mantém o código criptografado após a importação.

7. Atualizações da política

Esta política poderá ser atualizada caso as funcionalidades ou práticas de tratamento de dados da extensão sejam alteradas. A data de atualização será indicada nesta página.

8. Contato e solicitações de privacidade

Para dúvidas, sugestões ou solicitações relacionadas à privacidade, abra uma solicitação no repositório público de suporte e privacidade do Pacific Monkey. Evite enviar dados pessoais ou informações sensíveis em solicitações públicas.
